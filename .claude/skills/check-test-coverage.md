# 📊 스킬: 테스트 커버리지 강제 검증

이 스킬은 새롭게 작성된 코드의 신뢰성을 보장하기 위해 실행됩니다. 단순히 검사만 하는 것이 아니라 커버리지가 부족하면 스스로 코드를 더 짜도록 강제합니다.

## 🚪 적용 대상 (트리거 조건)
* **[MUST]** 변경된 모듈에 분기(if-else, switch, 예외 처리 등)가 있는 비즈니스 로직이 하나라도 있으면 반드시 실행합니다.
* **[면제]** 분기가 전혀 없는 순수 부트스트랩/설정 모듈(예: 인프라 서버의 `@SpringBootApplication` 진입점 하나만 있는 모듈)은 이 스킬 대상이 아닙니다 — Line/Branch 커버리지라는 지표 자체가 성립하지 않기 때문입니다. 이 판단은 "귀찮아서 건너뛴다"가 아니라 이 문서가 명시한 예외입니다.

## 🛠️ 실행 및 판정 파이프라인 (루트 pom에 jacoco-maven-plugin이 이미 연결되어 있습니다)
1. **[MUST]** 백엔드 디렉토리에서 `mvn clean test jacoco:report -pl {대상_모듈}`을 터미널로 실행합니다.
2. **[MUST]** 생성된 리포트 파일을 파싱하여 Line Coverage와 Branch Coverage 값을 추출합니다.
3. **[게이트웨이 검증]** 
   - Line Coverage가 **80%** 미만이거나, Branch Coverage가 **75%** 미만인 경우 **게이트 통과 실패**로 간주합니다.
4. **[강제 후속 조치]**
   - 통과 실패 시, 커버되지 않은 조건문(if-else)이나 메서드를 찾아내어 테스트 코드를 추가로 작성한 후 이 스킬을 다시 실행해야 합니다. 목표치를 달성할 때까지 커밋은 금지됩니다.
